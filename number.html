Number

Three ways to change a number, depending on how much the change should matter.

Spin

Digits roll through the numbers on a 3D drum, then land with a bounce.

For moments worth celebrating: points, rewards, milestones.

Pop

Changed digits leave upward as the new ones rise in and land with a bounce.

For updates people should notice: prices, totals, counters.

Subtle

Changed digits cross-fade in place, rising when up and falling when down.

For numbers that update often: live stats, dashboards, tickers.

Usage

import { createNumber } from "./number.js";

const count = createNumber(element, { type: "spin", value: 100 });

count.set(178);
